# Calculadora de Palés — Streamlit v4

Versión con campos numéricos vacíos al iniciar cada paso.

El `0,00` / `0` ya no aparece como valor escrito: se muestra como **placeholder**.
Así el trabajador puede empezar a escribir directamente sin tener que borrar el valor.

Incluye:
- Diseño responsive.
- Logo arriba a la derecha.
- Modo claro / oscuro.
- Flujo paso a paso.
- Cálculo del peso neto.
