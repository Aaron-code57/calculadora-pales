# Calculadora de Palés — Streamlit v3

Calculadora de peso neto paso a paso.

Incluye:
- Diseño responsive para ordenador, tablet y móvil.
- Logo de la empresa arriba a la derecha.
- Botón circular arriba para cambiar entre **modo claro y modo oscuro**.
- Cálculo del peso neto.
- Navegación atrás / continuar.
- Pantalla final sin desglose.

## Fórmula

`Peso neto = Peso total - Peso del palé - Peso del fardo - (Peso de una caja × Número de cajas)`

## GitHub + Streamlit

Sube `app.py`, `logo.png` y `requirements.txt` al repositorio.
En Streamlit selecciona `app.py` como archivo principal.
