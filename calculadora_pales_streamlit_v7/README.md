# Calculadora de Palés — Streamlit v7

Único cambio respecto a v6:

- El `0,00` / `0` del campo numérico vuelve a tratarse visualmente como placeholder transparente, para que el trabajador pueda escribir directamente sin tener que borrar un número visible.
- No se modifica el diseño, el logo, el modo claro/oscuro ni los botones.
